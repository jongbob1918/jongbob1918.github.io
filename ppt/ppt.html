01. JAVIS (자비스)

Type Team Project (9인)
Period 2024.09 - 2024.10
ROS 2 Nav2 Python
 GitHub Repository
Project Overview

도서관 및 카페 환경에서 안내, 서가 정리, 청소를 수행하는 다목적 모바일 매니퓰레이터입니다. 로봇팔과 주행부를 통합 제어하는 메인 시스템을 구축했습니다.

My Main Roles
  • 1. Robot Main Controller 개발 로봇의 행동을 State로 정의하여 시나리오 꼬임과 예외 상황을 방지하는 중앙 제어 시스템을 설계했습니다.
  • 2. 하드웨어 추상화 (Interface Design) HW 개발 지연에 대비해 Mock 객체 기반의 인터페이스를 설계, 장비 없이도 로직 검증이 가능한 환경을 구축했습니다.
  • 3. Navigation 최적화 좁은 통로(60cm) 주행을 위해 Costmap Inflation을 0.4m로 축소하고 MPPI 컨트롤러를 도입했습니다.
Troubleshooting
Problem: 좁은 통로 진입 불가
로봇 폭과 비슷한 좁은 통로에서 Costmap이 겹쳐 경로 생성이 실패하거나 제자리 회전 발생.
Solution
• Smac Planner Hybrid 도입으로 기구학적 제약을 고려한 경로 생성.
• Cost Penalty 완화 및 Inflation Radius 정밀 튜닝.

02. ROOMIE (루미)

Type Team Project (4인)
Role Arm Control, GUI, PM
ROS 2 Ikpy PyQt
 GitHub Repository
Project Overview

로봇팔을 이용해 스스로 엘리베이터 버튼을 조작하고 탑승하여 호텔 룸서비스를 수행하는 자율주행 배송 로봇입니다.

My Main Roles
  • 1. Robot Arm Controller (IK) ikpy를 활용해 카메라 좌표(Vision)를 관절 각도(Joint)로 변환하는 역기구학 솔루션을 구현했습니다.
  • 2. Motion Profile 구현 버튼 타격 시 떨림 방지를 위해 가우시안 함수 기반의 S-Curve 속도 프로파일을 적용했습니다.
  • 3. 통합 관제 GUI & PM PyQt 기반 다중 로봇 관제 대시보드 개발 및 Jira를 활용한 Agile 스프린트 관리를 수행했습니다.
Troubleshooting
Problem: 버튼 타격 오차 (Open-loop)
저가형 모터와 카메라 장착 오차로 인해 버튼을 헛누르는 현상 발생.
Solution
• Hand-Eye Calibration: 마커를 이용해 좌표 변환 행렬 정밀 보정.
• Action 분리: '정렬(Align)' 후 '누르기(Push)'를 수행하도록 동작 시퀀스 분리.
