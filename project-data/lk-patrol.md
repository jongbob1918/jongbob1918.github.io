## 수림과 잔디 구간에서의 위치 추정 오류

고양 서오릉은 [전체 면적이 약 187만 m²인 유적지](https://heritage.go.kr/heri/cul/culSelectDetail.do?ccbaAsno=0001980000000&ccbaCpno=1333101980000&ccbaCtcd=31&ccbaKdcd=13&pageNo=1_1_1_0)로, 수림과 수풀·잔디가 넓게 분포합니다. 순찰 구역에는 위치를 구분할 만한 특징이 부족한 구간이 있어, 센서 데이터를 사전 지도와 맞추는 로컬 정합(Local Matching)이 수 m 앞의 위치에 잘못 맞거나 실패하는 경우가 있었습니다.

기존 시스템은 로컬 정합에 실패하면 지도 전체에서 위치를 다시 찾는 전역 위치 추정(Global Localization)을 수행했습니다. 하지만 수만 평 규모의 사전 지도에서는 올바른 후보 위치를 찾기 어려웠고, 계산 부하도 커졌습니다.

### 지도를 나누고 전환 지점으로 연결

순찰 구역을 나눠 각각 지도를 작성하고, 지도 사이를 연결하는 경유점인 웨이포인트(Waypoint)를 지정했습니다. 로봇이 전환 지점에 도착하면 해당 구역의 지도를 불러오도록 해 한 번에 처리하는 지도 범위와 리소스 사용량을 줄였습니다.

### 현장 데이터를 재생하는 실험 환경 구축

알고리즘이나 파라미터를 바꿀 때마다 현장을 방문하기에는 날씨와 배터리 제약이 컸습니다. 기존에는 센서 데이터를 저장하고 재생하며 비교하는 실험 환경이 없어, 일주일 동안 현장 센서 데이터를 ROS 메시지 기록 도구인 rosbag으로 수집하고 반복 실험에 활용했습니다.

통과 기준과 알고리즘 후보·파라미터 조합을 정하고, 에이전트를 활용해 데이터 재생 실험을 병렬로 실행했습니다. 여러 기록 데이터에서 위치 추정이 틀어지지 않는 설정을 확인하고, 설정한 허용 범위 안의 로컬 정합 결과만 받아들이도록 제한했습니다.

자동 실험 결과만으로 판단하지 않고, 정합 후보가 잘못 선택되는 구간을 직접 시각화해 비교했습니다. 에이전트가 놓칠 수 있는 오정합을 확인하며 알고리즘과 파라미터를 조정했습니다.

## 맵 전환 후 초기 위치가 어긋나는 문제

분할된 지도에서 목표를 지정하면, 로봇이 필요한 맵 전환 웨이포인트를 거쳐 지도를 바꾸고 목표까지 이동하도록 구현했습니다. 하지만 전환한 지도에서 초기 위치를 정확히 지정하지 않으면 위치 추정이 어긋나는 문제가 발생했습니다.

이를 해결하기 위해 분할된 사전 지도들을 점군 정합 알고리즘인 ICP(Iterative Closest Point)로 맞추고, 지도 사이의 좌표 변환을 구해 공통 인터페이스에 저장했습니다. 맵 전환 웨이포인트가 두 지도에서 같은 실제 위치를 가리키도록 연결하고, 전환 후 초기 위치를 지정하는 데 활용했습니다. 이 방식으로 맵마다 따로 지정하던 전환 위치의 불일치를 줄였습니다.

## 경사와 단차를 고려한 장애물 인지

순찰 경로는 대부분 흙길이며, 평탄해 보이는 구간도 위치에 따라 고도가 다릅니다. 비가 오면 흙이 유실돼 길의 형태와 단차도 달라집니다.

기존 실내 주행용 장애물 인식은 로봇 기준 좌표계의 z축 높이를 기준으로 했습니다. 이 방식을 야외에 적용하자 지면의 고도가 달라지는 경사로나 단차 구간에서 주행 가능한 지면까지 장애물로 인식하는 문제가 있었습니다.

레이저로 주변의 3차원 형상을 측정하는 센서(3D LiDAR, Light Detection and Ranging)의 데이터에 지면 분리 알고리즘(Ground Segmentation)을 적용했습니다. 고정된 높이 기준 대신 지면과 장애물을 구분한 결과를 내비게이션에 반영해, 지형의 높이 변화를 고려하며 장애물을 회피하도록 수정했습니다.

## 출발 가속과 좁은 구간의 속도 명령 개선

바퀴형 이족 로봇의 강화학습 기반 주행 제어에서는 같은 속도 명령을 주어도 출발 시 급격한 가속이 나타났습니다. 당시 사용한 자율주행 소프트웨어 Nav2(Navigation2)의 Humble 버전 MPPI(Model Predictive Path Integral) 제어기에서 가속을 제한하는 방식을 검토했습니다. MPPI는 여러 후보 주행 궤적을 평가해 속도 명령을 만드는 제어기입니다.

먼저 지수 이동 평균 필터(EMA, Exponential Moving Average)를 적용해 속도 명령의 급격한 변화를 완화했습니다. 하지만 장애물 비용이 반영된 지도에서 통과 공간이 좁아지는 조건에서는 MPPI가 과도한 속도 명령을 출력하는 문제가 남았습니다.

Humble의 MPPI 구현을 분석한 뒤 Kilted 버전의 MPPI를 포팅해 가속과 좁은 구간의 과도한 속도 출력을 개선했습니다. Kilted 구현의 가속 제약은 [공식 소스 코드](https://api.nav2.org/nav2-kilted/html/motion__models_8hpp_source.html)에서 확인할 수 있습니다.

## 사람 접근 시 정지와 안내 방송

사람이 접근하면 회피 동작을 빈번하게 수행하던 방식에서, 설정한 안전 범위 안에 사람이 감지되면 정지하고 안내 방송을 하는 방식으로 변경했습니다. 사람이 함께 이용하는 순찰 공간에 맞춰 임무 수행 중의 예외 처리를 추가했습니다.

## 도킹과 언도킹

순찰로봇이 도킹 위치에 진입하는 도킹 기능과, 도킹 위치에서 이탈하는 언도킹 기능을 개발했습니다.

## 2 km 경로에서 반복 주행

기록 데이터로 위치 추정 설정과 정합 결과를 확인한 뒤, 서오릉의 순찰 경로에서 여러 차례 왕복 주행을 완료했습니다. 데이터 재생 실험과 현장 주행을 함께 활용해 위치 추정을 안정화했습니다.
