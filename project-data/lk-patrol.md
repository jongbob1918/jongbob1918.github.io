## Problem Statement

고양 서오릉은 [전체 면적이 약 187만 m²인 유적지](https://heritage.go.kr/heri/cul/culSelectDetail.do?ccbaAsno=0001980000000&ccbaCpno=1333101980000&ccbaCtcd=31&ccbaKdcd=13&pageNo=1_1_1_0)로, 수림과 수풀·잔디가 넓게 분포되어 있고, 산책로는 대부분 흙길이며 경사와 요철이 많고, 비가 오면 흙이 유실돼 지형도 달라집니다.

개발 과제는 이 환경에서 위치 추정을 유지하며 2 km 순찰 경로를 반복 주행하도록 만드는 것이었습니다.

## System Setup

바퀴형 이족 로봇에 로봇 소프트웨어 프레임워크인 ROS(Robot Operating System) 2와 자율주행 소프트웨어 Nav2(Navigation2)를 사용했습니다. 3D LiDAR(Light Detection and Ranging)와 카메라를 활용해 지도 작성·동시 위치 추정(SLAM, Simultaneous Localization and Mapping)과 자율주행을 수행했습니다.

상위 주행 모듈이 속도 명령을 전달하면 강화학습 기반 하위 제어기가 바퀴형 이족 로봇의 이동을 제어하는 구조입니다. 상위 모듈에서는 여러 후보 주행 궤적을 평가해 속도 명령을 만드는 MPPI(Model Predictive Path Integral) 제어기를 사용했습니다.

로봇이 대기 장소에 안전하게 진입해 대기할 수 있도록 정밀 정렬 알고리즘을 적용했습니다.

## Challenge 1: 야외환경에서의 위치 추정 틀어짐

### Problem

센서 데이터를 사전 지도와 맞추는 로컬 정합(Local Matching)이 수 m 앞의 위치에 잘못 맞거나 실패하는 경우가 있었습니다. 실패 후 지도 전체에서 위치를 다시 찾는 전역 위치 추정(Global Localization)도 올바른 후보를 찾기 어려웠고, 계산 부하가 커졌습니다.

### Root Cause

순찰 구역에는 위치를 구분할 만한 특징이 부족한 수림·잔디 구간이 있었습니다. 여기에 수만 평 규모의 사전 지도 전체를 탐색하면서 후보 위치를 구분하기 어려워지고 처리 범위도 커졌습니다.

### Solution

순찰 구역을 나눠 각각 지도를 작성하고, 경유점인 웨이포인트(Waypoint)로 연결했습니다. 목표를 지정하면 로봇이 필요한 맵 전환 지점을 거쳐 해당 구역의 지도를 불러오고 목표까지 이동하도록 했습니다.

이렇게 한 번에 처리하는 지도 범위를 줄이고, 설정한 허용 범위 안의 로컬 정합 결과만 받아들이도록 제한했습니다.

알고리즘과 파라미터를 바꿀 때마다 현장을 방문하기에는 날씨와 배터리 제약이 컸습니다. 일주일 동안 현장 센서 데이터를 ROS 메시지 기록 도구인 rosbag으로 수집하고, 데이터를 재생하며 비교하는 실험 환경을 구축했습니다.

통과 기준과 알고리즘 후보·파라미터 조합을 정한 뒤 에이전트를 활용해 재생 실험을 병렬로 실행했습니다. 정합 후보가 잘못 선택되는 구간은 직접 시각화해 비교하며, 자동 실험에서 놓칠 수 있는 오정합을 확인했습니다.

### Result

지도 분할로 처리 범위와 리소스 사용량을 줄였습니다. 수집한 여러 기록 데이터에서 위치 추정이 틀어지지 않는 설정을 확인하고 현장 주행에 적용했습니다.

## Challenge 2: 맵 전환 후 초기 위치 틀어짐

### Problem

지도를 분할한 뒤, 맵 전환 후 초기 위치를 정확히 지정하지 않으면 위치 추정이 어긋나는 문제가 발생했습니다.

### Root Cause

각 지도에서 따로 지정한 전환 위치가 같은 실제 위치를 가리키도록 맞춰져 있지 않았습니다. 새 지도의 좌표계에 맞는 초기 위치를 설정할 필요가 있었습니다.

### Solution

분할된 사전 지도들을 점군 정합 알고리즘인 ICP(Iterative Closest Point)로 맞추고, 지도 사이의 좌표 변환을 구해 공통 인터페이스에 저장했습니다. 전환 웨이포인트가 두 지도에서 같은 실제 위치를 가리키도록 연결하고, 이 정보를 전환 후 초기 위치 설정에 사용했습니다.

### Result

맵마다 따로 지정하던 전환 위치의 불일치를 줄이고, 두 지도의 좌표 관계를 이용해 초기 위치를 설정하도록 변경했습니다.

## Challenge 3: 경사·단차 구간의 장애물 인지 한계

### Problem

경사로나 단차 구간에서 주행 가능한 지면까지 장애물로 인식하는 문제가 있었습니다.

### Root Cause

기존 실내 주행용 인식은 로봇 기준 좌표계의 z축 높이로 장애물을 판별했습니다. 서오릉은 평탄해 보이는 구간도 고도가 다르고 강우로 지형이 변해, 고정된 높이 기준으로는 지면과 장애물을 구분하기 어려웠습니다.

### Solution

3D LiDAR 데이터에 지면 분리 알고리즘(Ground Segmentation)을 적용했습니다. 지면과 장애물을 구분한 결과를 내비게이션에 반영해, 지형의 높이 변화를 고려하며 장애물을 회피하도록 수정했습니다.

## Challenge 4: 네비게이션 가감속 불안정

### Problem

강화학습 기반 하위 제어기는 로봇의 과거·현재 상태에 따라 반응하므로, 실제 속도가 상위 주행 모듈의 속도 명령과 다르게 나타났습니다. 특히 출발 시 로봇이 기울어지면서 급격하게 가속하는 현상이 있었습니다.

### First Approach

지수 이동 평균 필터(EMA, Exponential Moving Average)를 적용해 속도 명령의 급격한 변화를 완화했습니다.

### Remaining Problem

장애물 비용이 반영된 지도에서 통과 공간이 좁아지는 조건에서는 MPPI가 과도한 속도 명령을 출력하는 문제가 남았습니다. 출력에 필터를 적용하는 것만으로는 충분하지 않아 제어기 구현을 분석했습니다.

### Solution

Humble 버전의 MPPI 구현을 분석해 좁은 구간에서 과도한 속도 명령이 출력되는 문제를 확인했습니다. 이후 Kilted 버전의 MPPI를 분석·포팅해 가속도를 제한하고, 좁은 구간의 과도한 속도 출력을 개선했습니다.

### Result

출발 시 가속과 좁은 구간의 과도한 속도 출력을 개선했습니다.

## Challenge 5: 방문객을 고려한 안전 규칙

### Problem

기존 컨트롤러로 주행할 때, 내비게이션은 장애물이 많아도 회피 경로를 만들어 주행을 이어갔습니다. 서오릉에 방문객이 많은 시간대에는 로봇에 관심을 보이며 가까이 다가오거나 둘러싸는 사람들이 있었습니다. 사람의 움직임은 예측하기 어려워, 회피 주행을 하더라도 충돌할 수 있다고 판단했습니다.

### Solution

로봇 주변에 안전 범위를 설정해 사람이 들어오면 정지하고, 범위 안에 사람이 없어지면 주행을 재개하도록 했습니다.

## Field Validation

기록 데이터로 위치 추정 설정과 정합 결과를 확인한 뒤, 서오릉의 순찰 경로에서 여러 차례 왕복 주행을 완료했습니다. 데이터 재생 실험과 현장 주행을 함께 활용해 위치 추정을 안정화했습니다.
