FALCON — 활주로 안전 관제 시스템

활주로의 FOD와 침입자를 탐지·추적하고 위험 상황을 관제 화면에 전달하는 비전 시스템입니다.

01

단일 프레임 탐지를 관제 정보로 확장

FALCON은 FOD·동물·작업자 등 활주로 위험요소를 영상에서 찾고, 객체별 이동 경로를 추적해 관제 화면에 전달하는 시스템입니다. 모델의 탐지 결과만 보여주는 데서 끝내지 않고 위험 판단과 시각화까지 연결했습니다.

핵심 결과 — 커스텀 학습 모델에서 정확도 90% 이상을 확인했습니다.

02

내 책임 범위

Dataset활주로 위험요소 학습 데이터 구성
DetectionYOLOv8 커스텀 학습과 성능 확인
Decision추적 결과 기반 위험 판단 로직

4인 팀 프로젝트이며, 이 페이지는 제가 담당한 지상 위험요소 탐지 모델과 위험 판단 로직을 중심으로 설명합니다.

03

탐지–추적–판단 파이프라인

카메라 프레임을 YOLOv8로 탐지하고 ByteTrack으로 객체 ID를 유지합니다. 추적 정보는 위험 판단 로직을 거쳐 관제 화면에 표시됩니다. 파란 테두리는 제가 담당한 범위입니다.

04

위험요소를 연속적인 사건으로 처리

커스텀 객체 탐지

활주로 환경의 FOD와 침입자를 대상으로 데이터를 구성하고 YOLOv8 모델을 학습했습니다.

객체 ID 유지

ByteTrack을 연결해 프레임이 바뀌어도 동일 객체의 ID와 이동 경로를 유지하도록 했습니다.

위험 판단

객체 종류와 추적 상태를 관제 로직의 입력으로 사용해 위험 상태를 화면에서 구분할 수 있도록 통합했습니다.

05

평가 조건을 함께 공개하는 검증

현재 확보된 결과는 커스텀 학습 모델의 정확도 90% 이상입니다. 다만 정확도가 precision, recall, mAP 중 어떤 지표인지와 데이터 분할 조건이 함께 제시돼야 재현 가능한 결과가 됩니다.

다음 업데이트에서 평가 지표명, 검증 데이터 수, confidence threshold를 저장소 README와 동일하게 명시합니다.
