01

엘리베이터 이용까지 포함한 룸서비스

ROOMIE는 투숙객 요청을 받아 객실까지 물품을 배송하는 서비스 로봇입니다. 층간 이동을 위해 로봇팔이 엘리베이터 버튼을 인식하고 정렬한 뒤 실제로 누르는 동작까지 수행해야 했습니다.

핵심 결과 — 하드웨어 제작과 소프트웨어 통합을 포함한 버튼 조작 시연을 38일 안에 완료했습니다.

02

내 책임 범위

Arm Controller3축 로봇팔 Action Server와 궤적 생성
Calibration카메라–로봇팔 좌표 변환과 정렬
GUI & 일정관제 인터페이스와 6회 스프린트 관리

4인 팀 프로젝트이며, 이 페이지는 제가 담당한 로봇팔 제어와 통합 관제 영역을 중심으로 설명합니다.

03

정렬과 누르기를 독립된 Action으로 구성

버튼 좌표는 Hand-Eye 변환을 거쳐 로봇 기준 좌표가 되고, IK 계산 후 정렬과 누르기 Action이 순서대로 실행됩니다. 파란 테두리는 제가 구현한 범위입니다.

04

버튼 조작을 단계별로 제어

ROS2 Action Server

정렬과 버튼 누르기를 비동기 Action으로 구성해 상위 제어기가 진행 상태와 완료 여부를 확인할 수 있게 했습니다.

IK와 좌표 변환

카메라에서 측정한 버튼 위치를 로봇 베이스 좌표로 변환하고, IK 해를 계산해 3축 관절 목표를 생성했습니다.

부드러운 궤적

급격한 가감속으로 발생하는 끝단 떨림을 줄이기 위해 가우시안 기반 속도 프로파일을 적용했습니다.

05

버튼 빗맞힘을 좌표와 동작 문제로 분리

증상
카메라에서 얻은 버튼 위치와 로봇팔의 실제 도달점 사이에 오차가 발생했습니다.
원인
카메라와 로봇팔의 물리적 장착 오차가 좌표 변환에 반영되지 않았고, 접근과 누르기가 한 동작에 결합돼 있었습니다.
변경
Hand-Eye Calibration으로 변환 행렬을 보정하고, 정면 정렬과 누르기를 별도 Action으로 분리했습니다.
재검증
버튼 인식부터 접근·정렬·누르기까지 연속 시연을 완료했습니다.
