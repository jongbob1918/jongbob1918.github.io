## 기울기 소실이란?

기울기 소실이란 딥러닝 학습에서 역전파알고리즘으로 가중치의 기울기들을 구하는데 층이 많아 질수록 입력층과 가까운 가중치들의 기울기가 점점 업데이트되지 않는 현상

활성화 함수에서 시그모이드를 사용시 시그모이드 그래프에서 최대 기울기의 위치하는 값은 0.5입니다. 

역전파를 위해 시그모이드함수를 미분하면 f(x) x (1- f(x)) 입니다.

최대 기울기의 미분값은 그럼 0.5 x (1-0.5) 입니다. 그럼 최대 기울기를 준다고 해도 0.25입니다. 

시그모이드 함수를 역전파하면 값이 0.25가 최대라고 하면 층이 많아 질수록 역전파로 구하는 기울기값들은 0에 가까워져 업데이트가 잘 안일어나는 현상이 발생합니다. 



해결방법 
활성화 함수의 변경
lelu
	양수의 출력값을 그대로 출력하고 음수를 0으로 출력하는 함수입니다. 
	양수는 그대로 출력하기 때문에 양수 부분에서 미분값은 1이고 음수는 0입니다. 그래서 층이 깊어져도 기울기가 잘전달되면서 복잡성을 유지합니다. 
	
	하지만 lelu가 기울기 소실을 완전히 해결하지않습니다. 
	음수를 0으로 만들기 때문에 층이 별로 없거나 노드가 적은 구간에서는 오히려 시그모이드보다 기울기 소실이 더 취약할 수있습니다. 
	
	lelu의 이런문제를 다이닝 노드라고 하는데 이런문제를 해결하기 위해서 lelu를 변형한 lesky lelu, gelu등이 나왔습니다. 
	활성화 함수 블로그편 링크 



배치 정규화 
	배치는 우리가 미니배치 경사하강법 할때 그 배치를 말한다. 즉 입력 데이터 의 수들을 뽀븡ㄹ때 임의 의 값을 뽑는다. 
	이 상황에서 모두 양수가 나온다면 선형함수는 lelu등 그대로 출력되는현상이 발생하고 , 모두 음수 면 기울기가 0이되버린다. 음수와 양수를 적절히 섞여서 입력되어야 가중치가 최적으로 나아진다. 
     그래서 입력받은 배치 수의 데잉터ㅇ를ㄹ 포함하여 입력받아 평균과 분산을 구한다 . 구한 평균과 분산을 가지고 평균은 빼고 분산은 나눈다. x-x
     / 1-1//	

	배치 정규화의 1차 목표는 데이터를 강제로 **평균 0, 분산 1**로 맞추는 것입니다. 
     
	  
	  그래서 활성화 함수 입력 앞단에 배치정규화 모듈을 추가한다. 들어오는 입력의 값들을 기반으로 
		데이터 1 - 평균 / 분산, 데이터2 - 평균 / 분산  ..... 데이터 5 - 평균/ 분산
		으로 바꿔준다. 이러면 데이터 의 각 0~1사이의 위치 에 적절히 분산된다. 
		하지만 시그모이드는 각 데이터의 구간만다 기울기가 다른기 때문에 어떤 부분은 미분값이 작게 된다. 이런 상황에서는 최적이 아닐수도있다. 활성화함수에 따라 최적의 재배치 기준을 알수없기 때문에 
		배치 정규화는 어디로 얼만큼 뿌릴지 계산합니다. 이를 위해 새로운 파라미터 r, b를 도입합니다. 
		r: scale b : shift , 
		r(x - 평균) + b 
		이제 역전파과정에서 해당 파라민터의 편미분을 구하는과정을 포함시키면 loss를 줄이는 방햐응로 재배치 윛치를 학습 
		배치 정규화 활성화 함수의 앞에 불일때도 많지만 뒤에 붙일 때도이싿. 
     배치 정구화는 
     학습과 테스트시 다ㅡㄹ게 동작합니다. 테스트 시에는 배치수가 하나이기때문에 평균과 분산이 오작동할가능성이 있습니다ㅏ. 학습시 ema를 사용하여 평균과 분산값을 저장합니다. 저장한 평균과 분사값을 사용합니다. 
배치 정규화의 단점
- 배치수에 따라 성능이 많이 편차가 커진다  배치수가 작으면 성능이 안좋아진다. 
-  피드포워드 모델(cnn, MLP)에서는 성능이 잘나오지만 RNN , Transformer 같은 시퀀스 데이터를 다루는 모델은 성능이 잘 안나온다. 왜냐하면 각 시점마다 다른데이터들이 나오는데 배치 정규화를 시키기가 어렵고 padding문제도 발생한다. 
     
레이어 정규화
-  주로 시퀀스 데이터로 시계열 데이터 모델에 적합하고, 배치수가 적어도 효과적으로 이용가능하다.
