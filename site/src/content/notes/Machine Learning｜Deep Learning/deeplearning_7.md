## 1. 기울기 소실이란?

기울기 소실은 역전파로 가중치의 기울기를 구할 때, 층이 많아질수록 입력층에 가까운 가중치의 기울기가 점점 작아져 업데이트가 일어나지 않는 현상입니다. 시그모이드나 tanh함수에서 주로 일어납니다.

## 2. 왜 일어날까

### 시그모이드 미분의 최댓값

역전파를 위해 시그모이드 $f(x)$를 미분하면 다음과 같습니다.

$$f'(x) = f(x)\,(1 - f(x))$$

기울기가 가장 큰 곳은 $x=0$이고, 이때 출력은 $f(0)=0.5$입니다. 그러므로 미분값의 최댓값은 다음과 같습니다.

$$0.5 \times (1 - 0.5) = 0.25$$

<img src="../../../../public/images/notes/easy-deep-learning-ch06/sigmoid-max-slope.png" alt="시그모이드 곡선에서 x=0일 때 출력 0.5인 점에 접선을 그어 기울기 0.25(최대)를 표시하고, x=−3과 x=3의 접선은 기울기가 0.05로 훨씬 완만함을 비교한 그림" width="560" height="342" loading="lazy" />

역전파에서는 층마다 이 미분값이 곱해집니다. 
가장 큰 값이 0.25이므로, 층이 많아질수록 입력층 쪽 기울기는 0에 가까워지고 업데이트가 잘 일어나지 않습니다.


## 3. 활성화 함수를 바꿔 해결하기

### ReLU

ReLU는 양수는 그대로 출력하고 음수는 0으로 출력하는 함수입니다.

<img src="../../../../public/images/notes/easy-deep-learning-ch06/relu.png" alt="입력 x가 음수인 구간에서는 출력이 0이고, x=0부터는 출력이 입력과 같아져 기울기 1의 직선으로 올라가는 ReLU 그래프" width="560" height="342" loading="lazy" />

양수 구간의 미분값은 1이고 음수 구간은 0입니다. 그래서 층이 깊어져도 기울기가 잘 전달되고, 모델의 복잡성도 유지됩니다.

### ReLU의 한계

ReLU도 기울기 소실을 완전히 해결하지는 못합니다.

음수를 0으로 만들기 때문에, 입력이 계속 음수인 노드는 출력과 기울기가 모두 0이 되어 더 이상 학습되지 않습니다. 
이를 Dying ReLU라고 합니다. 노드가 적은 층에서는 이 영향이 더 큽니다.

이 문제를 줄이려고 ReLU를 변형한 Leaky ReLU, GELU 등이 나왔습니다. 

자세한 내용은 [3장 활성화 함수](/notes/deep-learning/linear-nonlinear-activations/)에서 다뤘습니다.

## 4. 배치 정규화

여기서 배치는 [미니배치 경사하강법](/notes/deep-learning/easy-deep-learning-ch02/#6-미니배치-경사하강법)의 그 배치입니다. 

이 배치의 값이 모두 양수라면 ReLU는 입력을 그대로 내보내 선형 함수처럼 동작합니다. 
모두 음수라면 출력과 기울기가 0이 됩니다. 가중치가 잘 학습되려면 양수와 음수가 적절히 섞여 들어와야 합니다. 

이 모듈은 노드마다 가중합과 활성화 함수 사이에 둡니다.

<img src="../../../../public/images/notes/easy-deep-learning-ch06/batchnorm-position.png" alt="입력 두 개, 은닉 노드 세 개, 출력 두 개의 신경망. 은닉 노드마다 가중합(Σ)을 계산한 뒤 활성화 함수(f)에 들어가기 전에, 노드별로 따로 둔 둥근 모서리의 배치 정규화 모듈을 거친다" width="600" height="306" loading="lazy" />

노드 하나에 배치로 들어온 값의 평균 $\mu$와 분산 $\sigma^2$를 구하고, 각 값에서 평균을 빼고 표준편차 $\sigma$로 나눕니다.

$$\text{정규화한 값} = \frac{\text{입력값} - \text{평균}}{\text{표준편차}}$$

$$\hat{x}_i = \frac{x_i - \mu}{\sigma}$$

예를 들어 한 노드에 배치로 3, 9, 11, 17이 들어왔다고 해봅시다. 해당 값들은 아래처럼 위치됩니다. 

<img src="../../../../public/images/notes/easy-deep-learning-ch06/batch-values-relu.png" alt="노드 하나의 샘플 4개 값 3, 9, 11, 17이 한 열로 묶여 ReLU 노드로 들어간다. ReLU 그래프에서 네 값의 위치를 빨간 눈금으로 표시하면 모두 0보다 큰 오른쪽 직선 구간에 놓인다" width="600" height="304" loading="lazy" />

평균과 분산은 다음과 같습니다.

$$\mu = \frac{3+9+11+17}{4} = 10,\qquad \sigma^2 = \frac{(-7)^2+(-1)^2+1^2+7^2}{4} = 25,\qquad \sigma = 5$$

| | 값 1 | 값 2 | 값 3 | 값 4 |
|---|---|---|---|---|
| 입력 $x$ | 3 | 9 | 11 | 17 |
| $x-\mu$ | −7 | −1 | 1 | 7 |
| $\hat{x}=\dfrac{x-\mu}{\sigma}$ | −1.4 | −0.2 | 0.2 | 1.4 |

<img src="../../../../public/images/notes/easy-deep-learning-ch06/batch-values-batchnorm.png" alt="같은 샘플 4개 값이 배치 정규화 모듈을 거친 뒤 ReLU 노드로 들어간다. 앞 그림과 같은 눈금 범위의 ReLU 그래프에서 네 값이 −1.4, −0.2, 0.2, 1.4로 0 주변에 모이고, 빨간 눈금 두 개는 0 이하의 평평한 구간에, 두 개는 오른쪽 직선 구간에 놓인다" width="600" height="304" loading="lazy" />

이렇게 하면 값이 **평균 0, 분산 1**로 맞춰져 0 주변에 고르게 퍼집니다. 

양수와 음수가 섞여 활성화 함수로 들어갑니다. 위 예에서는 ReLU를 통과하면 0, 0, 0.2, 1.4가 되어, 음수는 0이 되고 양수만 남는 비선형 함수로 동작합니다.

### 감마와 베타로 위치를 학습하기

하지만 시그모이드는 구간마다 기울기가 달라서, 평균 0, 분산 1이 항상 최적은 아닙니다. 렐루도 적절한 분산이 최적의 성능을 낸다고 보장할 수 없습니다. 
활성화 함수에 따라 최적의 위치를 미리 알 수 없습니다.


그래서 배치 정규화는 어디로 얼마나 옮길지도 학습합니다. 이를 위해 파라미터 $\gamma$(scale)와 $\beta$(shift)를 둡니다.
$\gamma$는 값을 얼마나 넓게 퍼뜨릴지, $\beta$는 중심을 어디로 옮길지 정합니다.

$$y_i = \gamma \cdot \frac{x_i - \mu}{\sigma} + \beta$$

역전파에서 $\gamma$, $\beta$의 편미분도 구해서, 손실을 줄이는 방향으로 위치를 학습합니다.

배치 정규화는 활성화 함수 앞에 붙일 때가 많지만 뒤에 붙이기도 합니다.

### 학습할 때와 추론할 때

배치 정규화는 학습과 테스트에서 다르게 동작합니다. 
테스트에서는 배치가 하나라서 평균과 분산이 제대로 계산되지 않을 수 있습니다.

그래서 학습하는 동안 지수 이동 평균(EMA)으로 평균과 분산을 저장해 두고, 테스트에서는 저장한 값을 사용합니다.

### 배치 정규화의 한계

- 배치 크기가 작으면 성능이 나빠지고 편차도 커집니다.
- CNN, MLP 같은 피드포워드 모델에서는 잘 동작하지만, RNN이나 Transformer처럼 시퀀스 데이터를 다루는 모델에서는 성능이 잘 나오지 않습니다. 시점마다 다른 데이터가 들어와 정규화하기 어렵고, 패딩 문제도 생기기 때문입니다.



## 5. 레이어 정규화

배치 정규화는 노드 하나의 값으로, 배치의 샘플들에 걸쳐 평균과 분산을 구합니다.
레이어 정규화는 반대로 샘플 하나의 값으로, 층의 모든 노드에 걸쳐 평균과 분산을 구합니다.

<img src="../../../../public/images/notes/easy-deep-learning-ch06/layernorm-vs-batchnorm.png" alt="같은 은닉층 노드 3개의 비교. 배치 정규화는 노드마다 정규화 모듈이 하나씩 있어 노드 하나의 값을 샘플들에 걸쳐 정규화하고, 레이어 정규화는 모듈 하나가 층의 모든 노드를 감싸 한 샘플의 노드들에 걸쳐 정규화한다" width="600" height="295" loading="lazy" />


정규화한 뒤 $\gamma$, $\beta$로 위치를 학습하는 것은 배치 정규화와 같습니다.

다른 샘플을 쓰지 않으므로 배치 크기와 상관없고, 학습과 추론에서 똑같이 동작합니다.

그래서 배치 크기가 작을 때나 RNN, Transformer 같은 시퀀스 데이터 모델에서 주로 사용합니다.

## 6. 층을 깊게 쌓을 때 생기는 문제: "더 깊은데 왜 더 멍청해질까?"

ReLU, 배치 정규화, 초기화 기법 덕분에 기울기가 앞쪽 층까지 전달되게 되었습니다. 그러면 층을 더 쌓을수록 모델이 좋아져야 할 것 같습니다.

ResNet 논문(He 외, 2016)은 그렇지 않다는 결과를 보였습니다. CIFAR-10에서 56층 모델은 20층 모델보다 테스트 오차뿐 아니라 훈련 오차도 높았습니다. 이를 퇴행 문제(degradation problem)라고 부릅니다.



<img src="../../../../public/images/notes/easy-deep-learning-ch06/resnet-plain-20-56.png" alt="CIFAR-10에서 일반 네트워크 20층(노란 선)과 56층(빨간 선)의 반복 횟수별 훈련 오차(왼쪽)와 테스트 오차(오른쪽). 두 그래프 모두 학습 내내 56층의 오차가 20층보다 높다" width="700" height="230" loading="lazy" />

출처: K. He 외, *Deep Residual Learning for Image Recognition*, CVPR 2016, Figure 1

#### 1) 원인 분석

과적합이라면 깊은 모델이 훈련 데이터를 더 잘 맞혀 훈련 오차가 더 낮아야 합니다. 여기서는 훈련 오차부터 높습니다.

기울기 소실도 아닙니다. 논문은 배치 정규화를 넣은 상태에서 역전파되는 기울기의 크기가 정상인 것을 확인했습니다.

#### 2) 사고실험

여기서 논문 저자들은 흥미로운 **사고실험(Thought Experiment)** 하나를 제시합니다.

"이미 학습이 끝난 20층 모델 뒤에, 아무 계산도 하지 않고 입력을 그대로 흘려보내는 층($y = x$) 36개를 덧붙여 56층을 만들면 어떻게 될까?" 

덧붙인 36개 층은 데이터를 전혀 건드리지 않으므로, 이 모델의 훈련 오차는 20층 모델과 정확히 같습니다. 

이 사고실험이 시사하는 바는 명확합니다

**56층 신경망이 가질 수 있는 수많은 가중치 조합 중에는, "최소한 20층만큼은 완벽하게 해내는 조합"이 수학적으로 무조건 존재한다는 점입니다.** 

<img src="../../../../public/images/notes/easy-deep-learning-ch06/identity-thought-experiment.png" alt="세 줄의 층 블록 비교. 첫 줄은 20층 모델로 훈련 오차의 기준이다. 둘째 줄은 사고 실험의 56층으로, 20층을 그대로 복사한 뒤 점선으로 그린 항등 층(y=x) 36개를 덧붙여 훈련 오차가 20층과 같다. 셋째 줄은 처음부터 학습한 실제 56층으로, 훈련 오차가 20층보다 크다" width="700" height="268" loading="lazy" />

#### 3) 그런데 현실은? 

이 사고실험의 결과와 현실을 비교해 보면 아주 기묘한 모순이 생깁니다. 

- **이론 (사고실험):** 56층 모델은 최소한 20층만큼 하는 가중치 조합을 이미 품고 있음. 

* **현실 (실제 학습):** 56층을 처음부터 경사하강법으로 학습시키면, 20층보다 훨씬 처참한 성능이 나옴. 


 그렇다면 범인은 명확해집니다. 
 
"56층이라는 구조 자체가 나빠서가 아니라, 경사하강법이 그 정답 가중치 조합을 도저히 찾아가지 못하고 있다(Optimization Problem)"는 결론입니다. 

그렇다면 신경망은 왜 그 쉬워 보이는 '아무것도 안 하고 통과시키기($y = x$)'조차 스스로 찾아내지 못할까요?



일반적인 층(Plain Net)의 구조는 가중치 곱과 비선형 활성화 함수(ReLU)로 되어 있습니다.

$$y = \text{ReLU}(W \cdot x + b)$$
경사하강법은 전지전능하게 큰 그림을 보는 게 아니라, 발밑의 기울기(Gradient)만 보고 한 걸음씩 이동하는 알고리즘입니다.

여러 층을 거치며 이 비선형 변환들이 수십 번 중첩되면, 손실 함수 지형(Loss Landscape)은 엄청나게 울퉁불퉁해집니다. 그 복잡한 지형 속에서 경사하강법이 $y = x$가 되도록 가중치 $W$와 편향 $b$를 칼같이 맞추는 것은 **수많은 절벽 사이에서 실바늘 구멍을 통과하는 것**만큼 어렵습니다.

<img src="../../../../public/images/notes/easy-deep-learning-ch06/loss-landscape-skip.png" alt="손실 함수 지형을 3차원 곡면으로 그린 두 그림. 왼쪽 스킵 커넥션이 없는 신경망은 봉우리와 골짜기가 뾰족하게 솟은 울퉁불퉁한 지형이고, 오른쪽 스킵 커넥션이 있는 신경망은 가운데 최솟값을 향해 완만하게 내려가는 매끈한 그릇 모양이다" width="466" height="214" loading="lazy" />

출처: H. Li 외, *Visualizing the Loss Landscape of Neural Nets*, NeurIPS 2018, Figure 1

### 스킵 커넥션

 층 몇 개를 묶고, 이 층들을 통과한 하기 전 값을 통과한 입력값에 그대로 더하는 방식입니다.


<img src="../../../../public/images/notes/easy-deep-learning-ch06/resnet-residual-block.png" alt="ResNet의 잔차 블록. 입력이 3×3 합성곱 층 두 개를 차례로 지나는 동안, 오른쪽으로 돌아가는 화살표(x)가 입력을 그대로 가져와 ⊕에서 두 층의 출력 F(x)와 더하고, 그 결과가 ReLU를 거친다" width="260" height="218" loading="lazy" />



두 상자를 지나 ⊕에 들어가기 직전의 값을 $F(x)$라고 하면, ⊕의 출력은 다음과 같습니다.

$$y = F(x) + x$$


예를 들어 입력이 3이고 원하는 출력도 3이라고 해봅시다.

스킵 커넥션이 없으면 층들이 3을 직접 만들어야 합니다. 스킵 커넥션이 있으면 $F(3)$이 0만 내면 $0 + 3 = 3$이 됩니다.

층들이 0을 내려면 가중치를 0 쪽으로 보내기만 하면 됩니다. 비선형 층 여러 개로 $y=x$를 정확히 맞추는 것보다 훨씬 쉬운 목표입니다.

원하는 출력을 $H(x)$라고 하면, $F(x)$가 학습할 목표는 두 값의 차이인 $H(x)-x$입니다. 이 차이를 잔차(residual)라고 합니다.

이러한 Skip Connection이 있는 Block을 Residual Block이라고 하며 이러한 학습 방식을 이용하는 것이 Residual Learning이라고도 한다.
