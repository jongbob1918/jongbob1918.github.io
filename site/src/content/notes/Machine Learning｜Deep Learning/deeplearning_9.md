## CNN(Convolutional Neural Network)이란
이미지에서 물체를 분류하거나 특징을 추출할때 많이 사용하는 딥러닝 기술입니다. 합성곱 신경망은 인간의 시각처리 특징을 모방하여 만든 신경망입니다. 인간의 뇌는 이미지에서 각각의 특정 뉴런들이 특정 위치에 반응하거나 특정 특징(세로 패턴, 가로 패턴, 대각선 패턴 등등)을 반응하는 뉴런들이 각각 있는걸 발견하고 이 특징을 모방하여 만든것이 CNN입니다. 

### 왜 기존 신경망은 이미지처리를 잘못할까?
일반적인 완전연결 신경망(MLP)에 이미지를 넣으려면 2차원(흑백)이나 3차원(RGB 컬러) 형태의 픽셀 데이터를 **1차원 긴 줄(벡터)로 쫙 펴야** 합니다.

이 과정에서 치명적인 문제가 발생합니다.
- **공간 정보의 손실:** 위아래, 양옆으로 붙어 있던 픽셀들의 위치 관계가 전부 끊어집니다.
- **연산량 폭발:** 해상도가 조금만 커져도 모든 픽셀을 노드와 일일이 연결해야 하므로 학습해야 할 가중치(파라미터)가 기하급수적으로 늘어납니다.

## CNN의 작동원리
**[특징 추출(Conv + Pooling)]** 구간과 **[최종 분류(FC)]** 구간으로 나뉩니다. 먼저 이미지에서 핵심 특징을 뽑아내는 과정부터 살펴보겠습니다.

### 1. 컨볼루션 레이어(Conv Layer)
입력이미지 데이터에서 완전 연결되는 가중치 노드들이 아닌 부분적으로 연결되는 사이즈 (예: 3x3)인 노드를 사용합니다. 이 가중치와 노드를 필터(Filter, 또는 커널)라고 부르며 필터가 이미지의 왼쪽 위부터 오른쪽 아래까지 일정 간격으로 이동하며 훑습니다. 각 위치에서 픽셀 값과 필터의 가중치를 곱해 더하면서 이미지의 고유한 패턴을 찾아내는데, 이를 통해 만들어진 결과물을 특징 맵(Feature Map)이라고 부릅니다.
이때 동일한 필터를 가지고 재사용하므로 파라미터 수가 회기적으로 줄어듭니다.

- 입력 값에서 부분적으로 특정 가중치값이 잇는 커널을 사용하여 특정 특징이 남아잇는 특징맵을 만듬.
- **초기 층:** 가로선, 세로선, 대각선, 색상 경계 같은 단순한 특징을 포착합니다.
- **깊은 층:** 앞선 선들을 조합해 눈, 코, 바퀴, 나뭇잎 같은 고차원적인 형태를 인식합니다.

#### 패딩과 스트라이드
패딩은 컨볼루션 적용 전 이미지 테두리의 값을 추가하여 채워넣는 것을 말합니다. 이작업은 이미지크기 유지와 테두리 정보 보존을 위해 사용합니다.

기존 컨볼루션

패딩한 컨볼루션ㄴ 

일반적으로 제로 패딩을 사용하고 
아래 다른 패딩 방법도 있습니다.

- constrant padding : 0 또는 1로 지정된 상수값ㅇ로 패딩합니다. 
- replicate padding : 이미지의 가장자리 픽셀을 복제하여 padding합니다
	- 끝 픽셀을 쭉 잡아당긴 형태라 모서리에 **줄무늬(Streak) 패턴**이 생길 수 있습니다. 주로 연산이 단순해야 하거나 끝부분의 색상 톤만 유지하면 될 때 씁니다.

- reflect padding : 이미지의 경계를 거울처럼 반사시켜 padding합니다. 
	- 이미지의 질감과 변화 흐름이 자연스럽게 이어지기 때문에, 경계면에 인위적인 선이 생기는 것을 최소화합니다. 그래서 이미지 복원 스타일 변환, 세그멘테이션처럼 픽셀 단위의 정밀한 출력이 중요한 모델에서 선호합니다.

스트라이드는 커널이 한번에 몇칸을 이동하는 보폭을 의미합니다 
스트라이드를 키우면 세세한 특징보다 전반적인 특징을 키우는데 도움이 되고 계산량이 감소합니다. 하지만 너무 크면 정보손실을 발생시켜 모델의 선을저하를 일으킬수잇습니다.

### 2. 풀링 레이어(Pooling layer)
