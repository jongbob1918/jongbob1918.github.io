## 1. AI, ML, DL의 차이

### AI · 인공지능

인공지능(Artificial Intelligence)은 인간의 인식·추론 같은 지적 활동을 컴퓨터로 구현하는 분야다. 사람이 규칙을 정하는 **규칙 기반 방식**과 **데이터에서 학습하는 방식**을 포함한다.

### ML · 머신러닝

머신러닝(Machine Learning)은 데이터에서 패턴을 학습하는 방법이다. 사람이 판단 규칙을 모두 작성하는 대신, 데이터를 이용해 모델을 학습시킨다.

전통적인 머신러닝에서는 사람이 특징을 정하거나 전처리해서 넣는 경우가 많다. 딥러닝은 신경망으로 특징을 학습한다. 다만 **머신러닝은 정형 데이터, 딥러닝은 비정형 데이터로만 나뉘는 것은 아니다.**

많은 데이터에서 패턴을 찾아 분류 등에 활용할 수 있다는 장점이 있다. 분류 성능은 정확도 등으로 평가하며, 평가 지표는 작업에 따라 달라진다.

### DL · 딥러닝

딥러닝(Deep Learning)은 심층 신경망(Deep Neural Network)을 사용해 데이터에서 학습하는 머신러닝 방법이다.

![AI 안에 머신러닝이, 머신러닝 안에 딥러닝이 포함된 관계](/images/notes/easy-deep-learning-ch01/ai-ml-dl.svg)

## 2. AI가 이미지와 번역을 처리하는 방식

### 이미지

일반적인 8비트 RGB 이미지는 픽셀마다 빨강(R), 초록(G), 파랑(B) 값을 갖는다. 각 값은 0~255 범위이며, `(255, 255, 255)`는 흰색이다.

1. 픽셀 값을 R·G·B 채널별로 모으면 행렬 세 개가 된다.
2. 이 숫자 배열을 모델의 입력으로 사용한다.
3. 강아지 사진은 1, 고양이 사진은 0처럼 정답 레이블을 정한다.
4. 모델의 예측이 정답에 가까워지도록 학습한다.

모델은 사진 자체를 사람처럼 보는 것이 아니라, 사진을 표현한 숫자를 계산한다.

### 번역

텍스트는 **토큰화**(Tokenization)를 거쳐 처리한다. 토큰화는 문장을 적절한 텍스트 단위로 나누는 작업이다.

```text
나는 강사입니다 → [나는] [강사] [입니다]
I am an instructor. → [I] [am] [an] [instructor] [.]
```

위 분할은 설명용 예시다. 실제 토큰은 단어보다 작을 수도 있으며, 사용하는 토크나이저에 따라 달라진다.

1. 원문과 번역문을 각각 토큰으로 나눈다.
2. 토큰을 숫자 ID로 바꿔 모델에서 처리한다.
3. 원문과 번역문 쌍을 이용해 번역을 학습한다.
4. 출력된 토큰 ID를 다시 텍스트로 복원한다.

원문과 번역문의 토큰이 일대일로 대응하는 것은 아니다. 모델은 문맥과 어순을 고려해 번역문을 생성한다.

## 3. 머신러닝의 학습 방식

여기서는 배운 내용을 지도학습, 자기지도학습, 비지도학습, 강화학습으로 나누어 정리한다. 절대적인 구분은 아니며, 자기지도학습을 넓은 의미의 비지도학습에 포함하기도 한다.

### 3.1 지도학습

**입력과 정답을 함께 사용해 학습하는 방식.** 모델의 예측을 정답과 비교하면서 학습한다. 테스트에서는 정답을 입력하지 않고, 예측 결과를 평가하는 데 사용한다.

입력 데이터에 정답을 붙이는 작업을 **데이터 레이블링**(Data Labeling)이라고 한다.

#### 분류와 위치 추정

- **분류:** 이미지가 무엇을 나타내는지 클래스를 예측한다. 예: 강아지, 고양이.
- **객체 위치 추정:** 대상 객체의 위치를 예측한다. 보통 경계 상자로 표시한다.
- **객체 탐지:** 한 이미지에 있는 여러 객체의 종류와 위치를 함께 예측한다.

#### 분할

- **의미 분할:** 모든 픽셀에 대해 어떤 클래스에 속하는지 판단한다.
- **인스턴스 분할:** 같은 클래스라도 개별 객체를 구분한다. 사람 두 명이 있으면 각각 다른 영역으로 표시한다.

객체를 탐지한 뒤 각 객체 영역을 분할하는 구현 방식이 있다. 모든 인스턴스 분할이 이 순서를 따르는 것은 아니다.

#### 자세 추정과 얼굴 랜드마크 탐지

- **자세 추정(Pose Estimation):** 어깨·팔꿈치·무릎 등 주요 신체 부위의 좌표를 예측한다.
- **얼굴 랜드마크 탐지:** 눈·코·입 등 얼굴의 주요 특징점 좌표를 예측한다.

지도학습에는 정확한 레이블이 필요하다. 사람이 위치와 영역을 직접 표시하는 작업은 시간과 비용이 많이 든다.

### 3.2 자기지도학습

**사람이 붙인 레이블 대신, 데이터 자체에서 학습 목표를 만드는 방식.** 지도학습에 필요한 대량의 레이블링 부담을 줄일 수 있다.

#### 사전학습과 미세조정

| 단계 | 학습 내용 | 사용하는 데이터 |
| --- | --- | --- |
| 사전학습(Pretraining) | 보조 과제인 프리텍스트 작업(Pretext Task)을 풀며 특징 학습 | 사람이 붙인 레이블이 없는 데이터 |
| 미세조정(Fine-tuning) | 실제로 풀려는 다운스트림 작업(Downstream Task)에 맞게 모델 조정 | 해당 작업의 레이블이 있는 데이터 |

위는 대표적인 활용 흐름이다. 자기지도학습에 미세조정이 항상 필수인 것은 아니다.

#### Context Prediction · 위치 관계 예측

이미지의 작은 영역인 **패치** 사이의 상대 위치를 예측하면서 구조와 위치 관계를 학습한다.

1. 이미지에서 기준 패치를 무작위로 선택한다.
2. 기준 패치 주변에서 같은 크기의 패치를 선택한다.
3. 두 패치를 입력하고, 주변 패치가 기준 패치의 어느 방향에 있었는지 예측한다.

메모에서 ‘파란색 패치’는 기준 영역을 표시한 것이다. 실제 입력은 그 영역에서 잘라낸 이미지다.

패치의 위치는 추출 과정에서 알 수 있으므로 별도 레이블링 없이 여러 학습 쌍을 만들 수 있다. 이미지의 픽셀과 물체의 부분이 일정한 구조를 가진다는 점을 활용한다. [원 논문](https://arxiv.org/abs/1505.05192)

#### Contrastive Learning · 대조학습

같은 원본에서 나온 이미지의 표현은 가깝게, 다른 원본에서 나온 표현은 멀어지도록 학습하는 방식이다. 아래는 대표적인 이미지 대조학습 방식의 예다.

1. 하나의 이미지에 서로 다른 변형을 적용한다. 예: 일부 자르기, 밝기·색상 조절.
2. 변형된 이미지를 모델에 넣어 각각 숫자 벡터로 표현한다.
3. 같은 원본의 벡터는 가까워지고, 다른 원본의 벡터는 멀어지도록 모델을 조정한다.

![같은 원본의 두 변형은 가깝게, 다른 원본의 표현은 멀어지도록 학습하는 대조학습 도식](/images/notes/easy-deep-learning-ch01/contrastive-learning.svg)

**이미지의 특징은 어떻게 배우는가?** 두 변형에 공통으로 남는 정보를 찾아야 같은 원본의 표현을 가깝게 만들 수 있다. 이 방향으로 모델을 반복해서 조정하며 특징을 학습한다. 서로 다른 원본에 같은 종류의 물체가 있을 수 있다는 점은 구분해야 한다. [SimCLR 원 논문](https://arxiv.org/abs/2002.05709)

#### 자연어 처리

- **GPT:** 앞선 토큰을 보고 다음 토큰을 예측한다(Next Token Prediction).
- **BERT:** 문장의 일부를 가리고 해당 토큰을 예측한다(Masked Token Prediction). 원래 BERT는 두 문장 구간이 연속된 것인지 예측하는 작업(Next Sentence Prediction)도 사용했다.

두 방식 모두 원문으로부터 학습 목표를 만든다. [BERT 공식 설명](https://github.com/google-research/bert#what-is-bert)

### 3.3 비지도학습

**레이블이 없는 데이터에서 패턴이나 구조를 찾는 방식.** 군집화와 차원 축소가 대표적이다.

자기지도학습은 데이터에서 예측할 문제와 정답을 만든다. 여기서 다루는 비지도학습은 데이터의 유사성이나 분포를 이용해 구조를 찾는다. 데이터를 자르거나 변형하는지 여부가 둘을 나누는 기준은 아니다.

#### 군집화

비슷한 특징을 가진 데이터를 그룹으로 묶는다.

- **K-means:** 군집 수 K를 정하고, 가까운 중심에 데이터를 배정한 뒤 중심을 갱신하는 과정을 반복한다.
- **DBSCAN:** 데이터가 밀집한 영역을 그룹으로 묶는 밀도 기반 방법이다.

#### 차원 축소

중요한 특징을 가능한 한 유지하면서 데이터의 차원을 줄인다. 고차원 데이터의 시각화와 계산량 감소에 활용한다.

- **PCA · 주성분 분석:** 데이터의 분산을 크게 설명하는 방향으로 투영해 차원을 줄인다.
- **SVD · 특잇값 분해:** 행렬 분해 도구다. 일부 성분을 남기는 근사나 PCA 계산에 활용할 수 있다.

[군집화·차원 축소 참고 문서](https://scikit-learn.org/stable/unsupervised_learning.html)

### 3.4 강화학습

**행동의 결과로 받는 보상을 이용해, 누적 보상이 커지는 행동을 학습하는 방식.** 게임의 승점이나 로봇의 목표 도달 보상 등을 학습에 사용할 수 있다.

보상을 주는 것만으로 원하는 행동이 보장되지는 않는다. 행동을 시도하고 결과를 확인하는 경험이 필요하다.

![행동을 선택하는 에이전트와 관측·보상을 돌려주는 환경의 상호작용](/images/notes/easy-deep-learning-ch01/reinforcement-learning.svg)

#### 자주 나오는 용어

| 용어 | 의미 | 예시·메모 |
| --- | --- | --- |
| Agent · 에이전트 | 행동하는 주체 | 학습하는 강아지, 로봇 |
| Action · 행동 | 에이전트가 특정 시점에 선택한 행동 | 왼쪽 이동, 관절 움직이기 |
| Reward · 보상 | 행동 결과에 따라 받는 수치 신호 | 승점, 목표 도달 보상 |
| Environment · 환경 | 에이전트가 상호작용하는 대상 | 게임판과 상대, 로봇의 주변 환경 |
| State · 상태 | 환경의 현재 상황을 나타내는 정보 | 위치, 관절 상태 등 |
| Q-function · 행동 가치 함수 | 특정 상태에서 행동한 뒤 주어진 행동 방식을 따를 때 얻는 할인 누적 보상의 기대값 | 현재와 미래의 보상을 함께 평가 |
| Episode · 에피소드 | 시작부터 종료까지 하나의 완전한 시행 | 게임 한 판, 로봇 이동 한 번 |
| Q-learning | 행동과 보상의 경험으로 Q값을 반복 갱신하는 방법 | 최적의 행동 가치 학습 |
| Exploration · 탐색 | 더 나은 선택을 찾기 위해 행동을 시도하는 것 | 알고 있는 좋은 행동을 선택하는 활용(Exploitation)과 균형 필요 |
| Discount factor · 할인율 γ | 미래 보상의 반영 정도를 조절하는 값 | 작을수록 먼 미래 보상의 영향이 줄어듦 |

ε-greedy 방식에서는 확률 **ε**로 무작위 행동을 선택한다. ε가 클수록 탐색을 더 자주 한다.

할인율은 **r이 아니라 γ**(감마)로 표기한다. 보통 `0 ≤ γ < 1`을 사용하며, 유한한 에피소드 등에서는 1을 사용할 수도 있다. [강화학습 용어 참고](https://spinningup.openai.com/en/latest/spinningup/rl_intro.html)
