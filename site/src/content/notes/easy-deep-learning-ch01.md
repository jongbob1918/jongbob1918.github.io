『이지 딥러닝』 1장을 읽고, **AI·머신러닝·딥러닝의 관계와 네 가지 학습 방식**을 정리했다. 이미지 분류와 번역을 예로 들어 모델의 입력을 살펴보고, 각 학습 방식이 무엇을 단서로 배우는지 비교한다.

## AI, 머신러닝, 딥러닝의 관계

**딥러닝은 머신러닝의 한 방법이고, 머신러닝은 AI에 포함된다.**

![AI 영역 안에 머신러닝이 있고, 머신러닝 영역 안에 딥러닝이 포함된 관계도](/images/notes/easy-deep-learning-ch01/ai-ml-dl.svg)

**인공지능(Artificial Intelligence, AI)**은 인식·추론·계획처럼 지능이 필요한 일을 컴퓨터로 수행하게 하는 넓은 분야다. 사람이 규칙을 작성하는 방식과 데이터에서 학습하는 방식을 모두 포함한다.

**머신러닝(Machine Learning, ML)**은 데이터나 경험에서 패턴을 학습하는 방법이다. 예를 들어 강아지를 구분하는 규칙을 사람이 하나씩 작성하는 대신, 이미지와 정답을 이용해 모델을 학습시킬 수 있다.

**딥러닝(Deep Learning, DL)**은 여러 층으로 이루어진 신경망을 사용하는 머신러닝 방법이다. 신경망의 층을 거치면서 작업에 필요한 데이터의 특징을 학습한다.

머신러닝과 딥러닝을 구분하는 기준은 정형·비정형 데이터 여부가 아니다. 딥러닝도 표 형태의 데이터를 다룰 수 있고, 다른 머신러닝 방법도 이미지에서 추출한 특징을 사용할 수 있다.

## 모델에 이미지와 문장을 넣는 방법

모델이 계산할 수 있도록 **이미지와 텍스트를 숫자로 표현한다.**

### 이미지는 RGB 숫자 배열로 바꾼다

일반적인 8비트 컬러 이미지는 픽셀마다 빨강(R), 초록(G), 파랑(B) 값을 가진다. 각 값의 범위는 0~255다. 예를 들어 `(255, 0, 0)`은 빨강, `(255, 255, 255)`는 흰색이다.

채널별 값을 모으면 행렬 세 개가 된다. 높이가 H, 너비가 W인 이미지를 `H × W × 3` 형태의 다차원 배열, 즉 텐서로 표현할 수 있다.

```text
입력: 강아지 사진 → RGB 숫자 배열
정답: 강아지 = 1, 고양이 = 0
학습: 모델의 예측과 정답의 차이를 줄인다.
```

여기서 0과 1은 클래스를 구별하기 위해 정한 레이블이다.

### 문장은 토큰으로 나누고 숫자로 바꾼다

**토큰화(Tokenization)**는 텍스트를 모델이 처리할 단위로 나누는 작업이다. 토큰은 단어 전체일 수도 있고 단어의 일부나 문자일 수도 있다.

```text
나는 강사입니다
    ↓ 토큰화 예시
[나는] [강사] [입니다]
    ↓ 숫자로 표현
토큰 ID → 임베딩 벡터
    ↓ 번역 모델
출력 토큰 ID → I am an instructor.
```

실제 토큰 분할은 토크나이저에 따라 달라진다. 토큰 ID가 각 토큰을 구별하는 번호라면, 임베딩은 신경망이 계산에 사용하는 숫자 벡터다.

번역 모델은 원문과 번역문 쌍으로 학습할 수 있다. 언어마다 어순과 토큰 수가 다르므로, 원문 토큰을 하나씩 고정 대응시키기보다 **문맥을 고려해 번역문을 생성한다.**

## 학습 방식은 무엇을 보고 배우는지로 비교한다

입력을 숫자로 표현했다면, 다음은 모델이 무엇을 기준으로 학습하는지 살펴볼 차례다.

| 방식 | 학습의 단서 | 예시 |
| --- | --- | --- |
| 지도학습 | 입력과 짝지어진 정답 | 강아지·고양이 분류 |
| 자기지도학습 | 데이터 자체에서 만든 목표 | 가려진 토큰 예측 |
| 비지도학습 | 데이터의 유사성과 구조 | 비슷한 데이터 묶기 |
| 강화학습 | 행동 이후의 보상과 경험 | 목표까지 이동하기 |

여기서는 책을 읽으며 배운 내용을 네 가지로 나눴다. 이 구분이 절대적인 것은 아니며, 자기지도학습을 넓은 의미의 비지도학습에 포함하기도 한다.

## 지도학습: 입력과 정답으로 배운다

강아지 사진에 ‘강아지’라는 정답을 붙여 학습시키는 것이 **지도학습(Supervised Learning)**의 예다. 모델의 예측을 정답과 비교하고, 오차가 줄어들도록 모델을 조정한다.

평가할 때는 학습에 쓰지 않은 데이터를 입력한다. 정답은 모델에 알려주지 않고, 예측 결과를 채점하는 데 사용한다.

### 어떤 결과를 예측하는가

| 작업 | 예측하는 결과 |
| --- | --- |
| 분류 | 사진 속 대상이 강아지인지 고양이인지 |
| 객체 위치 추정 | 대상 객체를 둘러싼 경계 상자 |
| 객체 탐지 | 여러 객체의 종류와 각각의 위치 |
| 의미 분할 | 각 픽셀이 도로·사람·차량 중 무엇인지 |
| 인스턴스 분할 | 사람 A와 사람 B를 구분한 픽셀 영역 |
| 자세 추정 | 어깨·팔꿈치·무릎 등 신체 부위의 좌표 |
| 얼굴 랜드마크 탐지 | 눈·코·입의 주요 특징점 좌표 |

분류 외에 집값이나 온도처럼 연속적인 수치를 예측하는 **회귀**도 있다. 따라서 평가 지표도 문제에 맞게 선택한다. 분류에서는 정확도 등을, 회귀에서는 예측 오차를 살펴본다.

**지도학습에는 정답 데이터가 필요하다.** 레이블은 기존 기록이나 측정값에서 얻기도 하지만, 사람이 이미지마다 위치와 영역을 표시해야 한다면 상당한 시간과 비용이 든다.

## 자기지도학습: 데이터에서 학습 목표를 만든다

**자기지도학습(Self-Supervised Learning)**은 사람이 레이블을 일일이 붙이는 부담을 줄이는 방법이다. 데이터의 일부나 관계를 이용해 모델이 맞혀야 할 목표를 만든다.

예를 들어 문장에서 단어를 가리면, 원래 단어가 곧 정답이다. 별도의 사람이 정답을 작성하지 않아도 학습할 수 있다.

### 이미지 패치의 위치를 맞힌다

위치 관계 예측(Context Prediction)은 이미지에서 작은 영역인 **패치** 두 개를 잘라, 한 패치가 다른 패치의 어느 방향에 있었는지 맞히는 작업이다.

패치를 어디에서 잘랐는지는 이미 알고 있다. 따라서 위치 정답을 자동으로 만들 수 있다. 모델은 패치의 관계를 예측하면서 물체의 부분과 구조에 유용한 특징을 학습한다. [원 논문](https://arxiv.org/abs/1505.05192)

### 같은 이미지의 두 변형을 가깝게 만든다

**대조학습(Contrastive Learning)**의 대표적인 방법인 SimCLR에서는 한 이미지를 서로 다르게 자르거나 색상을 바꿔 두 입력을 만든다.

![같은 원본에서 만든 두 이미지의 표현은 가깝게, 다른 원본의 표현은 멀어지도록 학습하는 도식](/images/notes/easy-deep-learning-ch01/contrastive-learning.svg)

이미지를 숫자 벡터로 바꾸는 신경망을 **인코더**라고 한다. 같은 원본에서 나온 두 벡터는 가까워지고, 다른 원본에서 나온 벡터는 멀어지도록 손실을 계산한다. 그 손실을 줄이며 인코더를 조정하면, 변형 후에도 공통으로 남는 특징을 학습할 수 있다. [SimCLR 원 논문](https://arxiv.org/abs/2002.05709)

*그림의 점은 고차원 벡터를 단순화한 표현이다. 서로 다른 원본에도 같은 종류의 물체가 있을 수 있다.*

### 문장의 다음 토큰이나 빈칸을 맞힌다

| 예시 | 사전학습 목표 |
| --- | --- |
| GPT 계열의 기본 언어 모델 학습 | 앞선 토큰을 보고 다음 토큰 예측 |
| BERT의 마스크 언어 모델 | 주변 문맥을 보고 가려진 토큰 예측 |

두 경우 모두 원문에서 학습 목표를 얻는다. 원래 BERT에는 두 문장 구간이 실제로 이어지는지 판단하는 ‘다음 문장 예측’도 포함됐다. [BERT 공식 설명](https://github.com/google-research/bert#what-is-bert)

### 배운 특징을 실제 작업에 활용한다

대표적인 활용 흐름은 **사전학습 → 미세조정**이다. 레이블 없는 데이터에서 특징을 먼저 배우고, 실제 작업의 레이블로 모델을 조정한다.

사전학습용 보조 과제를 **프리텍스트 작업(Pretext Task)**, 실제로 풀려는 문제를 **다운스트림 작업(Downstream Task)**이라고 한다. 미세조정 외에, 사전학습한 모델을 고정하고 특징 추출에 사용하는 방법도 있다.

## 비지도학습: 비슷한 데이터를 묶고 구조를 찾는다

**비지도학습(Unsupervised Learning)**은 정답 레이블 없이 데이터의 패턴과 구조를 찾는다. 대표적인 작업은 군집화와 차원 축소다.

**군집화(Clustering)**는 비슷한 특징을 가진 데이터를 묶는다. K-means는 군집 수 K를 정하고 가까운 중심에 데이터를 배정하며 중심을 갱신한다. DBSCAN은 데이터가 밀집한 영역을 군집으로 묶고, 떨어진 점을 잡음으로 구분할 수 있다.

**차원 축소(Dimensionality Reduction)**는 중요한 구조를 가능한 한 유지하면서 더 적은 변수로 데이터를 표현한다. 시각화나 계산량 감소에 활용하지만, 정보를 일부 잃을 수 있다.

| 방법 | 역할 |
| --- | --- |
| 주성분 분석(PCA) | 분산을 크게 설명하는 방향을 찾아 낮은 차원으로 투영 |
| 특잇값 분해(SVD) | 행렬 분해 도구. 저랭크 근사나 PCA 계산 등에 활용 |

자기지도학습과 비교할 때는 **데이터에서 예측 목표를 어떻게 만드는지**에 주목하면 좋다. 데이터를 자르거나 변형하는지 여부만으로 두 방식을 구분할 수는 없다. [scikit-learn 비지도학습 문서](https://scikit-learn.org/stable/unsupervised_learning.html)

## 강화학습: 행동의 장기적인 결과로 배운다

목표까지 이동하는 로봇을 생각해 보자. 로봇은 행동을 선택하고, 환경에서 그 결과와 보상을 받는다. 이 경험을 이용해 **누적 보상을 크게 만드는 행동 방식**을 배우는 것이 강화학습(Reinforcement Learning)이다.

![에이전트가 환경에 행동을 보내고 다음 관측과 보상을 받아 다시 행동을 선택하는 순환 도식](/images/notes/easy-deep-learning-ch01/reinforcement-learning.svg)

행동을 선택하는 주체가 **에이전트(Agent)**, 상호작용하는 대상이 **환경(Environment)**이다. 에이전트가 행동을 정하는 방식을 **정책(Policy)**이라고 한다.

로봇 이동에서는 목표 도달에 보상을 주고 충돌에 불이익을 줄 수 있다. 학습은 당장의 보상뿐 아니라 이후 얻을 보상도 고려한다. 원하는 행동을 배우게 하려면 보상과 관측을 적절히 설계하고 충분히 경험하도록 해야 한다.

### 탐색과 활용

**탐색(Exploration)**은 더 나은 선택을 찾기 위해 행동을 시도하는 것이고, **활용(Exploitation)**은 현재 가장 좋다고 판단한 행동을 선택하는 것이다.

대표적인 ε-greedy 방식은 확률 ε로 무작위 행동을 선택하고, 나머지 확률로 현재 행동 가치가 가장 높은 행동을 선택한다. ε가 클수록 무작위 행동을 더 자주 시도한다.

### Q값과 할인율

**행동 가치 함수(Q-function)**는 현재 상태에서 특정 행동을 한 뒤, 이후 특정 정책을 따를 때 얻을 할인 누적 보상의 기대값이다. 행동의 가치를 미래 보상까지 고려해 평가하는 것이다.

미래 보상에는 **할인율 γ(감마)**를 적용한다. 보상이 차례로 1, 2, 3이고 γ가 0.9라면, 이 경로의 할인 누적 보상은 다음과 같다.

```text
1 + 0.9 × 2 + 0.9² × 3 = 5.23
```

γ가 작을수록 먼 미래 보상의 영향이 줄어든다. 위 계산은 한 경로의 결과이고, Q값은 가능한 미래 결과에 대한 기대값이다.

**Q-learning**은 경험을 이용해 Q값을 갱신하는 방법이다. 기본적으로 ‘이번 보상 + 할인한 다음 상태의 최대 Q값’을 목표로 현재 추정치를 조정한다.

<details>
<summary>강화학습 용어와 표기 더 보기</summary>

| 용어 | 의미 |
| --- | --- |
| 상태(State) | 환경의 현재 상황을 설명하는 정보 |
| 관측(Observation) | 에이전트가 실제로 받는 정보. 상태의 일부일 수 있음 |
| 행동(Action) | 특정 시점에 선택한 행동 |
| 행동 공간(Action Space) | 가능한 행동 전체의 집합 |
| 보상(Reward, r) | 행동 결과를 평가하는 수치 신호 |
| 에피소드(Episode) | 시작부터 종료까지의 한 시행 |

할인율은 보통 `0 ≤ γ < 1`을 사용하며, 유한한 에피소드 등에서는 `γ = 1`을 사용할 수도 있다. Q-learning의 갱신은 에피소드 종료 전에도 가능하다. ε-greedy는 탐색 방법의 한 예이며, 모든 강화학습이 ε를 사용하는 것은 아니다.

## 1장에서 기억할 세 가지

- **AI·ML·DL은 포함 관계다.** 딥러닝은 여러 층의 신경망을 사용하는 머신러닝 방법이다.
- **입력은 숫자로 표현한다.** 이미지는 RGB 배열로, 문장은 토큰 ID와 임베딩으로 처리한다.
- **학습의 단서를 구분한다.** 정답, 데이터에서 만든 목표, 데이터의 구조, 행동의 보상을 이용해 배운다.

이제 남는 질문은 모델을 실제로 어떻게 바꾸느냐는 것이다. 예측의 오차를 수치로 표현하는 방법과, 그 오차를 줄이도록 신경망의 가중치를 조정하는 과정을 이어서 공부하려고 한다.
