## 1. AI, ML, DL의 차이

### AI · 인공지능

인공지능(Artificial Intelligence)은 인간의 인식·추론 같은 지적 활동을 컴퓨터로 구현하는 분야다. 사람이 규칙을 정하는 **규칙 기반 방식**과 **데이터에서 학습하는 방식**을 포함한다.

### ML · 머신러닝

강아지는 품종·자세·조명에 따라 모습이 달라진다. 이런 경우를 사람이 규칙으로 모두 작성하기는 어렵다. **머신러닝**(Machine Learning)은 데이터를 이용해 모델이 판단에 필요한 패턴을 학습하도록 한다.

전통적인 머신러닝에서는 사람이 특징을 정하거나 전처리해서 넣는 경우가 많다. 딥러닝은 신경망으로 특징을 학습한다. 다만 **머신러닝은 정형 데이터, 딥러닝은 비정형 데이터로만 나뉘는 것은 아니다.**

많은 데이터에서 패턴을 찾아 분류 등에 활용할 수 있다는 장점이 있다. 분류 성능은 정확도 등으로 평가하며, 평가 지표는 작업에 따라 달라진다.

### DL · 딥러닝

이미지나 음성에서 어떤 특징을 뽑아야 할지 사람이 일일이 정하기는 어렵다. **딥러닝**(Deep Learning)은 심층 신경망(Deep Neural Network)을 이용해 작업에 필요한 특징까지 학습하는 머신러닝 방법이다.

## 2. AI가 이미지와 번역을 처리하는 방식

### 이미지

일반적인 8비트 RGB 이미지는 픽셀마다 빨강(R), 초록(G), 파랑(B) 값을 갖는다. 각 값은 0~255 범위이며, `(255, 255, 255)`는 흰색이다.

픽셀 값을 R·G·B 채널별로 모으면 행렬 세 개가 된다. 아래 그림은 강아지 사진을 세 채널과 숫자 행렬로 표현한 예시다.

</figure>

분류를 학습할 때는 이 숫자 배열을 입력으로 사용하고, 정답 레이블을 별도로 붙인다.

- **입력:** 강아지 또는 고양이 사진의 RGB 숫자 배열
- **정답:** 강아지는 1, 고양이는 0처럼 정한 레이블
- **학습:** 모델의 예측이 정답에 가까워지도록 조정

픽셀 값은 사진을 표현하는 숫자이고, 정답 레이블은 사진의 종류를 표시하는 숫자다.

### 번역

문장은 길이가 제각각이고 그대로는 숫자 계산에 사용할 수 없다. **토큰화**(Tokenization)로 문장을 처리 가능한 단위로 나눈 뒤, 각 토큰을 숫자 ID로 바꾼다.

```text
나는 강사입니다 → [나는] [강사] [입니다]
I am an instructor. → [I] [am] [an] [instructor] [.]
```

위 분할은 설명용 예시다. 실제 토큰은 단어보다 작을 수도 있으며, 사용하는 토크나이저에 따라 달라진다.

1. 원문과 번역문을 각각 토큰으로 나눈다.
2. 토큰을 숫자 ID로 바꿔 모델에서 처리한다.
3. 원문과 번역문 쌍을 이용해 번역을 학습한다.
4. 출력된 토큰 ID를 다시 텍스트로 복원한다.

원문과 번역문의 토큰이 일대일로 대응하는 것은 아니다. 모델은 문맥과 어순을 고려해 번역문을 생성한다.

## 3. 머신러닝의 학습 방식

여기서는 배운 내용을 지도학습, 자기지도학습, 비지도학습, 강화학습으로 나누어 정리한다. 절대적인 구분은 아니며, 자기지도학습을 넓은 의미의 비지도학습에 포함하기도 한다.

### 3.1 지도학습

강아지 사진을 모델에 넣었을 때, 예측이 맞았는지 판단할 기준이 필요하다. **지도학습**은 입력에 정답을 붙이고, 예측과 정답의 차이를 줄이도록 학습하는 방식이다. 테스트에서는 정답을 입력하지 않고 평가에만 사용한다.

입력 데이터에 정답을 붙이는 작업을 **데이터 레이블링**(Data Labeling)이라고 한다.

#### 분류와 위치 추정

사진에 무엇이 있는지만 알면 되는지, 어디에 몇 개 있는지도 알아야 하는지에 따라 작업이 달라진다.

- **분류:** 이미지가 무엇을 나타내는지 클래스를 예측한다. 예: 강아지, 고양이.
- **객체 위치 추정:** 대상 객체의 위치를 예측한다. 보통 경계 상자로 표시한다.
- **객체 탐지:** 한 이미지에 있는 여러 객체의 종류와 위치를 함께 예측한다.

#### 분할

경계 상자만으로는 물체의 정확한 모양을 표현하기 어렵다. **분할**은 픽셀 단위로 영역을 구분한다.

- **의미 분할:** 모든 픽셀에 대해 어떤 클래스에 속하는지 판단한다.
- **인스턴스 분할:** 같은 클래스라도 개별 객체를 구분한다. 사람 두 명이 있으면 각각 다른 영역으로 표시한다.

구현 예시: 객체 탐지 → 각 객체 영역의 픽셀 분할

#### 자세 추정과 얼굴 랜드마크 탐지

- **자세 추정(Pose Estimation):** 어깨·팔꿈치·무릎 등 주요 신체 부위의 좌표를 예측한다.
- **얼굴 랜드마크 탐지:** 눈·코·입 등 얼굴의 주요 특징점 좌표를 예측한다.

지도학습에는 정확한 레이블이 필요하다. 사람이 위치와 영역을 직접 표시하는 작업은 시간과 비용이 많이 든다.

### 3.2 자기지도학습

데이터가 많아도 사람이 정답을 붙이는 데는 시간과 비용이 든다. **자기지도학습**은 데이터 자체에서 학습 목표를 만들어 레이블링 부담을 줄이는 방식이다.

#### 사전학습과 미세조정

실제 작업의 레이블이 적으면 충분한 학습이 어려울 수 있다. 대표적인 활용 흐름은 **레이블 없는 데이터로 먼저 특징을 학습하고, 실제 작업의 레이블로 모델을 조정하는 것**이다.

| 단계 | 학습 내용 | 사용하는 데이터 |
| --- | --- | --- |
| 사전학습(Pretraining) | 보조 과제인 프리텍스트 작업(Pretext Task)을 풀며 특징 학습 | 사람이 붙인 레이블이 없는 데이터 |
| 미세조정(Fine-tuning) | 실제로 풀려는 다운스트림 작업(Downstream Task)에 맞게 모델 조정 | 해당 작업의 레이블이 있는 데이터 |

#### Context Prediction · 위치 관계 예측

이미지에 정답 레이블이 없어도 어디에서 잘라낸 조각인지는 알 수 있다. 이 위치 정보를 학습 목표로 사용하는 방법이 **Context Prediction**이다. 작은 이미지 영역인 패치 사이의 상대 위치를 예측한다.

1. 이미지에서 기준 패치를 무작위로 선택한다.
2. 기준 패치 주변에서 같은 크기의 패치를 선택한다.
3. 두 패치를 입력하고, 주변 패치가 기준 패치의 어느 방향에 있었는지 예측한다.

패치의 위치는 추출 과정에서 알 수 있으므로 별도 레이블링 없이 여러 학습 쌍을 만들 수 있다. 이미지의 픽셀과 물체의 부분이 일정한 구조를 가진다는 점을 활용한다. [원 논문](https://arxiv.org/abs/1505.05192)

#### Contrastive Learning · 대조학습

사진을 자르거나 밝기를 바꿔도 같은 대상의 특징을 유지할 필요가 있다. **대조학습**에서는 같은 원본의 두 변형을 한 쌍으로 만들어, 공통된 특징을 학습하게 한다. 아래는 SimCLR 방식의 예다.

1. 하나의 이미지에 서로 다른 변형을 적용한다. 예: 일부 자르기, 밝기·색상 조절.
2. 변형된 이미지를 모델에 넣어 각각 숫자 벡터로 표현한다.
3. 같은 원본의 벡터는 가까워지고, 다른 원본의 벡터는 멀어지도록 모델을 조정한다.

두 변형의 표현이 가까워지도록 모델을 조정하면서, 변형 후에도 공통으로 남는 특징을 학습한다. [SimCLR 원 논문](https://arxiv.org/abs/2002.05709)

#### 자연어 처리

- **GPT:** 앞선 토큰을 보고 다음 토큰을 예측한다(Next Token Prediction).
- **BERT:** 문장의 일부를 가리고 해당 토큰을 예측한다(Masked Token Prediction). 원래 BERT는 두 문장 구간이 연속된 것인지 예측하는 작업(Next Sentence Prediction)도 사용했다.

두 방식 모두 원문으로부터 학습 목표를 만든다. [BERT 공식 설명](https://github.com/google-research/bert#what-is-bert)

### 3.3 비지도학습

**레이블이 없는 데이터에서 패턴이나 구조를 찾는 방식.**

대표 예시: 군집화, 차원 축소

자기지도학습은 데이터에서 예측할 문제와 정답을 만든다. 여기서 다루는 비지도학습은 데이터의 유사성이나 분포를 이용해 구조를 찾는다.

#### 군집화

정답 분류가 없는 데이터에서 비슷한 사례끼리 묶어 보고 싶을 때 사용한다. **군집화**는 데이터의 특징을 비교해 그룹을 찾는다.

- **K-means:** 군집 수 K를 정하고, 가까운 중심에 데이터를 배정한 뒤 중심을 갱신하는 과정을 반복한다.
- **DBSCAN:** 데이터가 밀집한 영역을 그룹으로 묶는 밀도 기반 방법이다.

#### 차원 축소

데이터의 변수가 많으면 계산량이 늘고, 분포를 눈으로 확인하기도 어렵다. **차원 축소**는 중요한 특징을 가능한 한 유지하면서 변수 수를 줄이는 방법이다.

활용 예시: 고차원 데이터 시각화, 계산량 감소

- **PCA · 주성분 분석:** 데이터의 분산을 크게 설명하는 방향으로 투영해 차원을 줄인다.
- **SVD · 특잇값 분해:** 행렬 분해 도구다. 일부 성분을 남기는 근사나 PCA 계산에 활용할 수 있다.

[군집화·차원 축소 참고 문서](https://scikit-learn.org/stable/unsupervised_learning.html)

### 3.4 강화학습

오목을 배우는 AI가 있다고 하자. 목표는 상대를 이기는 것이다. 하지만 돌의 배치가 바뀔 때마다 사람이 “여기가 정답”이라고 알려주기는 어렵다. 지금 둔 수가 승리에 도움이 됐는지도 나중에야 알 수 있다.

#### 매 수의 정답 대신 경기 결과를 알려준다

각 수의 정답을 알려주는 대신, 경기 결과에 보상을 정한다.

- **승리:** +1
- **패배:** −1
- **진행 중·무승부:** 0

AI는 돌을 놓고 상대의 응수를 보면서 경기를 진행한다. 이런 경험을 반복하며, 결과적으로 보상을 많이 얻는 수를 선택하도록 학습한다. 이것이 **강화학습**이다.

  <img src="/images/notes/easy-deep-learning-ch01/gomoku-setup.png" alt="검은 돌 두 개와 흰 돌 두 개가 놓인 오목 초반의 예시 판. 노란 원은 놓인 검은 돌을 표시한다." width="420" loading="lazy" />

이 예시에서 기본 용어는 다음과 연결된다.

| 용어 | 오목에서의 의미 |
| --- | --- |
| Agent · 에이전트 | 수를 선택하는 AI |
| Environment · 환경 | 오목판, 게임 규칙, 상대의 응수 |
| State · 상태 | 현재 돌의 배치와 차례 |
| Action · 행동 | 둘 수 있는 빈칸 중 한 곳에 돌을 놓는 것 |
| Reward · 보상 | 위에서 정한 승리 +1, 패배 −1 등의 점수 |
| Episode · 에피소드 | 시작부터 승패 또는 무승부가 결정될 때까지 한 판 |


#### 아직 승패가 나지 않았는데 어떤 수를 고를까?

위 판에서 검은 돌을 둘 곳을 비교해 보자.

| 후보 | 위치 | 이번 수의 보상 |
| --- | --- | --- |
| A | 나란히 놓인 검은 돌 두 개의 바로 왼쪽 빈 교점 | 0 |
| B | 판의 왼쪽 위 모서리 교점 | 0 |

어느 쪽도 당장 다섯 돌을 완성하지 못한다. **이 수를 둔 뒤 얻을 미래 보상**까지 평가해야 두 선택을 비교할 수 있다.

이때 사용하는 것이 **행동 가치 함수**(Q-function)다. 현재 상태에서 특정 행동을 하고, 이후 정해진 행동 방식을 따를 때 얻는 할인 누적 보상의 기대값을 나타낸다.

예를 들어 현재 추정치가 `Q(A) = 0.6`, `Q(B) = 0.2`라면 AI는 A칸을 더 좋은 선택으로 평가한다. 이 값은 학습 중인 추정치이며, 승리를 보장하는 점수는 아니다.

#### A칸만 선택하면 B칸의 가능성을 놓친다

현재 Q값이 높다는 이유로 A칸만 선택하면, B칸에서 시작하는 더 좋은 전략을 발견하지 못할 수 있다. 그렇다고 매번 무작위로 두면 이미 배운 좋은 수를 활용하지 못한다.

그래서 **탐색과 활용의 균형**이 필요하다.

- **탐색**(Exploration): 더 좋은 수를 찾기 위해 다른 선택을 시도
- **활용**(Exploitation): 현재 Q값이 가장 높은 수를 선택

##### 방법 예시: ε-greedy

탐색과 활용을 확률로 나누는 방법이다. `ε = 0.1`로 정했다면 매번 수를 고를 때 다음 규칙을 적용한다.

- **10% 확률:** 둘 수 있는 빈칸 중 무작위로 선택
- **90% 확률:** 현재 Q값이 가장 큰 칸을 선택

ε가 클수록 무작위 선택을 더 자주 한다. 무작위로 고른 결과가 현재 가장 좋은 수와 같을 수도 있다.

#### 몇 수 뒤의 승리까지 얼마나 반영할까?

경기가 진행되어 검은 돌 네 개가 나란히 놓인 상황을 보자. 아직 보상은 0이지만, 상대가 한쪽을 막아도 반대쪽에서 다섯 돌을 완성할 수 있다.

</figure>

이처럼 당장 받은 보상이 0이어도 앞으로 승리 보상을 받을 수 있다. 미래 보상을 현재 평가에 얼마나 반영할지 정하는 값이 **할인율 γ**(감마)다.

계산 예시로 돌아가, 초반의 A칸 선택부터 받을 보상이 `0 → 0 → +1`이고 `γ = 0.9`라고 가정하자. 여기서는 내가 수를 두고 상대가 응수한 뒤 다음 수를 고르기까지를 한 단계로 본다.

| 시점 | 보상 | 현재 평가에 반영되는 값 |
| --- | --- | --- |
| 현재 | 0 | 0 |
| 한 단계 뒤 | 0 | 0.9 × 0 = 0 |
| 두 단계 뒤 | +1 | 0.9² × 1 = 0.81 |

**합계: 0.81**

- **γ가 작을수록:** 먼 미래에 받을 승리 보상의 영향이 작아짐
- **γ가 1에 가까울수록:** 먼 미래 보상도 더 많이 반영

위의 0.81은 한 경로에서 계산한 값이다. Q값은 상대의 응수 등 여러 가능한 결과를 고려한 기대값이다. 이처럼 한 판이 끝나는 문제에서는 γ를 1로 두고 할인하지 않는 설정도 가능하다.

#### 끝나고 받은 보상을 이전 수의 평가에 반영한다

다섯 돌이 이어지면 승리 보상 +1을 받는다.

<figure>
  <img src="/images/notes/easy-deep-learning-ch01/gomoku-win.png" alt="검은 돌 다섯 개가 가로로 이어지고 초록 선으로 승리한 줄을 표시한 오목 예시 판." width="420" loading="lazy" />
  <figcaption>출처: <a href="https://asobigame.com/game/gomoku">Asobi Game · 오목 안내</a>.</figcaption>
</figure>

마지막 수뿐 아니라 그 전에 둔 수들도 승리에 기여했을 수 있다. 이전 수의 평가에도 이 결과를 반영할 방법이 필요하다.

**Q-learning**은 경험한 상태·행동·보상·다음 상태를 이용해 Q값을 갱신하는 방법이다. 다음 상태에서 선택할 수 있는 수 중 가장 큰 Q값을 현재 보상과 함께 사용한다.

```text
현재 Q값을 조정할 목표
= 이번에 받은 보상 + γ × 다음 상태의 최대 Q값
```

다음 상태의 최대 Q값이 1이고 이번 보상이 0이라면, `γ = 0.9`일 때 목표값은 0.9다. 현재 Q값을 이 목표에 가까워지도록 조정한다. 경기가 종료됐다면 다음 행동이 없으므로 마지막 보상만 사용한다.

이런 갱신을 반복하면서 승패의 결과가 이전 수들의 평가에도 반영된다. 갱신은 한 판이 끝난 뒤뿐 아니라 진행 중에도 할 수 있다. [강화학습 개념·가치 함수 참고](https://spinningup.openai.com/en/latest/spinningup/rl_intro.html)
